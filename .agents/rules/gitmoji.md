# Messages de commit

- Chaque message de commit commence par un gitmoji (https://gitmoji.dev),
  suivi d'un type et d'une description courte en français.
- Exemples :
  - ✨ feat: ajoute le filtre des tâches faites
  - 🐛 fix: corrige l'enregistrement d'une tâche vide
  - ✅ test: ajoute les tests de la suppression
  - 📝 docs: complète le README
